# モグラたたき

**ver. 1.0.0**

ブラウザだけで遊べる30秒ミニゲーム。
「ほかのゲーム」枠の見た目・アニメーション改善シリーズ、1本目です。

## 方針

ルール（30秒・9穴・たたくと+1・逃したらミス+1・だんだん速くなる・ベスト記録の保存）は**従来どおり**。
見た目・アニメーション・画面サイズ対応だけを作り直しました。
遊び心地・難易度は変えていないので、前と同じ感覚で遊べます。

## 変えたところ

### 見た目

- **モグラをSVGで描き直した** — 絵文字から、耳・ひげ・前歯・肉球のついたオリジナルのモグラに。
  画面サイズが変わっても輪郭が崩れません。
- **表情の切り替え** — たたいたときは目が×になり、逃げるときは舌を出します。
  たまに出てくるうさぎも描き起こしました。
- **穴まわりを立体的に** — 奥に暗い穴、手前に土のふち、足もとにゆれる草。
  モグラが穴の奥からのぞいている形が自然になりました。
- **背景を描き込んだ** — 流れる雲、光を放つ太陽、三層の丘。動き続ける背景で待ち時間も退屈しません。
- **フィールドに小花** — 芝生に小さな花を散らしました。

### アニメーション

- **出てくる動き** — バネのように少し行き過ぎてから戻るイージングで、ニュッと出る感触に。
  出るときに土がパラパラ舞います。
- **たたいた瞬間** — ハンマーを振り下ろす → モグラがつぶれる → 星が飛び散る → 白い輪が広がる → 「+1」が浮かぶ → 画面がわずかに揺れる。
- **ミスのとき** — 「にげた〜」と白いオーラが上がり、コンボが途切れます。
- **コンボ** — 3連続から「n COMBO!」が出て、弾むように表示されます。
- **スコアの数字** — 加点のたびに弾みます。
- **タイマーバー** — ストライプが流れ続け、残り10秒で黄色、5秒で赤く脈打ちます。
- **カウントダウン** — 開始前に「3・2・1・GO!」、終了時に「タイムアップ！」が大きく出ます。
- **結果画面** — スコアがカウントアップし、ランクのバッジが弾み、命中率のバーが伸びます。
  15点以上なら紙吹雪が舞います。

### その他

- **音** — Web Audio で合成した効果音（ヒット／ミス／カウントダウン／ファンファーレ）。
  外部ファイルなしで鳴ります。右上のボタンでミュート可。
- **画面サイズ対応** — スマホ縦・スマホ横・PCに合わせて、フィールドが入りきる最大サイズになります。
  横向きで高さが低いときは、左にスコア・右にフィールドの2カラム配置に切り替わります。
- **ゲーム時間で進行** — タブを離れると止まるので、裏に回っても不利になりません。
- **PC向け** — キーボードの `7 8 9 / 4 5 6 / 1 2 3`（QWER/ASD/ZXC も可）でもたたけます。
  マス目にもキーの印が出ます。
- **動きを控えめに設定している端末** — OSで「動きを減らす」を選んでいると、アニメーションが止まります。
- **ベスト記録・ミュート設定は保存されます**（localStorage）。

## 変えていない中身

- 制限時間 30秒／3×3の9穴
- 経過時間とともに、出現間隔とモグラの滞在時間が短くなる
- 中盤から2体同時に出ることがある
- 逃すとミス+1
- たまに出るうさぎも、モグラと同じく+1
